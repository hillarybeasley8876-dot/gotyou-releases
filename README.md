# 抽到你了 GOT YOU — Releases

你退坑三年的抽卡游戏《星愿回廊》今晚 00:00 停服。你点开了那条回归推送——金光里抽出来的，是你自己。
她叫小愿。她等了你 1095 天。

第一人称「先甜后恐怖」的原创小品游戏（Godot 4.7）。含惊吓（突脸）演出：暂停菜单（Esc）→「惊吓演出」可以选「标准 / 减弱」。

本仓库只放发布二进制：Windows 包。源码不在此公开。下载见 [Releases](../../releases)。

## 版本

**v1.5（候选版）**

本版更新：

- 第四话「……该走了」之后下山：她现在是一路走下去的（以前会一段段瞬移过去）；下山的路也接好了，不会再掉出地面。
- 章节之间的场景切换：她不会再留在上一个场景的坐标里往下掉。
- 她的动作：不会再「原地走路」（脚在迈、人不动）；走路时两条手臂自然摆动；站着等你的时候是安安静静的站姿，带一点呼吸和重心的小动作；转身、起步不再一下子甩过去——先转过来再走，从长椅上起身会先站起来；坐、躺、跪都落在看得见的床垫 / 椅面上，不再悬空；鞋底在平地上不再陷进地板。
- 她的脸：睫毛、眉毛、眼线不再是白色的面片；不说话时嘴不再张着；恐怖段里眼睛的光点落在眼睛上。
- 恐怖：新增「突脸」——四个恐怖小游戏被抓到的那一瞬间、以及剧情里几处固定的位置；出现之前会先安静下来。暂停菜单（Esc）→「惊吓演出」可以选「标准 / 减弱」。
- 读档：从存档「继续」时，她、你站的位置、灯光都和连着玩到那里时一样（以前「继续」的开头几句她可能不在屋里）。
- 交互：所有必须按 E 的地方都能走过去按到；屏幕上同一时间只会出现一个「[E]」，写的就是按下去会发生的事；小游戏进行中不会再出现按了没反应的「拆开信」；躲起来被找到时不会和她挤在一起。
- 稳定性：修好了「开始新游戏后进入序章时闪退」，以及第八话→第九话、演唱会换场时的闪退；每一章开头不再闪过她的头发 / 一帧怪姿势；第一话开场恢复成从一片白里慢慢亮起来。
- 画面：演唱会中场休息时大屏不再发白；镜头换机位时会眨一下眼，不再瞬间跳过去。
- 其它：F3 显示帧数（给想自己看看卡不卡的人）。

已知问题：

- 走石阶下山（第四话「……该走了」、祭典去帐篷、鬼抓人冲下石阶）时，她的脚偶尔还会陷进台阶或悬在台阶上方——脚部贴地还在做，下一版修。
- 最终话她坐在终端高凳上时，两只鞋悬在半空。
- 最终话那一下无声的特写，撤掉时还有一下硬切。
- 第十一话最后一下突脸之后，会先回到走廊、再出章节卡。
- 比心的手势还比较简化。
- 开新档后她第一次出现的头几秒（约 5–8 秒），马尾上的星星发夹看不见，之后自己回来（「继续游戏」那条路已经修好）。
- 第八话开头（偷看了手机的那条线），章节卡过后她会在画面里一下子挪到照片墙前，接着甩两下头、叠出一个半透明的残影（约 1 秒）。
- 第九话开场，白光散去的那一下舞台会突然亮一下（约 0.2 秒）。
- 捉迷藏 / 潜行时，如果你自己从躲藏点出来，她可能会径直走到你身上（镜头会钻进她的头发里）。
- 潜行小游戏里，她巡逻时「看见你」的视野方向是反的（站在她面前反而不容易被发现）——v1.4 起就这样，下一版修。
- 潜行时她起步后有时会贴着墙横着滑一下（约 1 秒）。
- 真结局（E1）最后两个镜头里，她的小腿和办公椅的椅面穿在一起。

## 运行要求

- Windows 10 / 11 64 位，支持 Vulkan 的显卡。
- 第一次启动要编译着色器，可能卡 10–20 秒，属正常。
- 存档自动保存在 `%APPDATA%\Godot\app_userdata\抽到你了 GOT YOU\`；从旧版本升级直接用新文件夹里的 GotYou.exe，存档会自动接上。
- 游戏里的怪事都只发生在游戏里：不读写你电脑上的其他文件、不联网、不弹系统窗口；会读 Windows 用户名来称呼你（不保存、不上传）。
